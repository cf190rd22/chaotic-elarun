          Which token scopes do I need?
          

            
Recommended: fine-grained token. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate.
              Set Repository access to Only select repositories and pick just your backup repo.
              Under Repository permissions set Contents: Read and write. Metadata: Read-only is added automatically. Nothing else is needed. Give it an expiry date.

            
Classic token: needs the repo scope for a private repo (public_repo only covers public repos, and a public backup repo would publish your data). Classic tokens grant access to every repo you own, so prefer fine-grained.

            
Where the token lives: only in this browser's IndexedDB, never in exports or backups. It is sent only to api.github.com. Note that every page on the same origin can read it: on GitHub Pages all your project sites share username.github.io, which is another reason to scope the token to one repo.

            
Use a private repo. Org repos with SAML SSO need the token authorised for that org.
